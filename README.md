# snapix
Outil de screenshot simple mac &amp; windows
NAPIX — captures d'écran et annotations
=======================================
SUR MAC (macOS 13 ou plus récent)
1. Téléchargez « Snapix.zip » et double-cliquez dessus pour le décompresser.
2. Glissez « Snapix.app » dans le dossier Applications.
3. Ouvrez Snapix. macOS indique qu'il ne peut pas vérifier le développeur :
   allez dans Réglages Système › Confidentialité et sécurité, descendez en bas
   et cliquez sur « Ouvrir quand même » à côté de Snapix, puis confirmez.
4. À la première capture, Snapix demande l'autorisation « Enregistrement de l'écran » :
   cliquez sur « Ouvrir les Réglages », activez Snapix, puis cliquez sur « Relancer Snapix ».

Raccourcis : Option+Maj+4 = zone, Option+Maj+5 = fenêtre, Option+Maj+3 = plein écran,
Option+Maj+2 = copier le texte d'une zone. Icône appareil photo dans la barre des menus.

DANS L'ÉDITEUR
Choisissez un outil (flèche, rectangle, texte, flou…), dessinez, puis déplacez la forme avec
l'icône main ou agrandissez-la avec les poignées. « Copier » ou « Enregistrer » ferme l'éditeur.
